# LX Music 车机版

`Tingfe/lx-music-car` 是独立维护的 Android 车机应用，不再与手机 APK 共用发布仓库。当前版本为 **1.8.29**。

## 车机交互原则

- **车机尺寸**：直接使用 dp，不再按手机屏幕比例缩放；字号偏好只影响文字，不改变触控区域。手机版保留原有缩放逻辑。
- **控制优先**：上一首、播放/暂停、下一首各有 76×76dp 触控区；歌曲行高 84dp，右侧“更多”独立保留 76dp，避免误触播放。
- **低干扰**：强制横屏，沿用 v1.8.26 的系统栏策略：导航层隐藏系统栏，车机不渲染 React Native 状态栏组件；原生 Activity 不强制沉浸式或全屏。本次不调整原车窗口策略。
- **双主题可读性**：深色主题用于夜间低眩光，浅色主题用于白天高对比；两者使用相同的布局、强调色语义与触控尺寸，可在主页顶栏一键切换。
- **窗口兼容**：允许系统重设任务尺寸，以兼容会将第三方应用安排在左侧窗格、并在右侧保留导航或原车应用的 Android 8.1 车机 Launcher。
- **信息层级**：侧栏宽 150dp，品牌区高 44dp，搜索、歌单、我的列表三个主入口不低于 76dp；设置和退出横向收纳在底部工具区。
- **可扫读**：主页信息栏 52dp、二级浏览栏 56dp；歌曲标题字号 22、次要信息 16。列表按自身测得的宽度排列，小于 1080dp 为单列，足够宽时才显示双列，不再根据物理屏幕长宽比猜测。
- **在线歌单**：96dp 封面的横向卡片，标题字号 20（最多两行）、次要信息 16；按内容宽度排列 1–3 列，多列时卡片宽度不低于 300dp。整张卡片可打开歌单。
- **本地歌单**：我的列表展开区使用 76dp 行高、20 号标题和独立 76dp 更多按钮，当前歌单高亮，选择与更多操作互不干扰。
- **底部播放栏**：歌曲信息与控制区分离，最小高度 124dp；内容宽度小于 560dp 时上下排列，最小高度 212dp。长标题截断，不挤走按钮；空播放禁用无效控制，提示可进入我的列表。歌词保留在播放详情，进度条遵循原有允许点击设置。
- **跨页一致性**：歌单/标签抽屉限制在可用宽度的 72%，榜单导航 152–208dp，设置导航 160–216dp；筛选、输入和设置控件沿用车机触控尺度。
- **反馈层级**：歌单、音源、同步与设置复用的对话框、更多菜单和底部弹层均使用 56dp 标题/关闭区、64dp 菜单项和不小于 180dp 的操作菜单；深浅主题下保持同一状态与文本对比关系。
- **驾驶舱视觉**：车机主页移除手机背景图；夜间使用深灰蓝底，白天使用低反差浅灰白底，并以青绿色作为唯一的关键状态强调色。
- **驾驶安全**：播放控制保留在首页固定底栏；同步、音源编辑、导入导出等低频操作收纳到设置页。
- **操作逻辑**：轻触歌曲立即播放；点当前歌单名称展开列表切换；歌曲更多操作维持在右侧独立按钮中，减少误触播放。长按、多选、导入等复杂操作不作为行驶中的主流程。
- **浏览优先**：浏览页只保留底部播放栏，不显示重复的顶部播放概览。沿用本地保存的上次播放、歌单选择与列表位置，不因为 UI 升级清空数据。
- **实体媒体键**：当前版本已经可由车机实体媒体键控制播放；该能力继续复用 Android 音频会话，不以模拟按键方式覆盖或干扰原车按键处理。
- **设备隔离**：语言、主题、音频输出、窗口和车机显示参数不参与跨端同步，避免手机或桌面端错误覆盖车机配置。
- **在线遥控**：车机连接同步服务后会登记为受控设备；同账号手机会轮询最新在线状态，可在车机在线时切歌、播放/暂停，或把手机当前歌曲交由车机解析播放。离线时不接收缓存命令。

## 安装与升级

1. 在 [Releases](https://github.com/Tingfe/lx-music-car/releases) 下载最新版本；测试版标记为 Pre-release。
2. WEY VV5 2020 这类 Android 8.1 车机安装唯一的 `universal.apk` 文件。
3. 首次启动会直接横屏显示。部分原车系统会在右侧保留导航或原车应用，这是系统窗口策略；LX 会适配左侧主应用区。在「设置 → 数据同步服务」中填写你的同步服务地址和账号。
4. 应用内检查更新只会下载本仓库的车机 APK，不会下载手机端安装包。

旧车机版若使用同一包名 `cn.toside.music.mobile.car` 且签名相同，可以直接覆盖安装；Android 提示签名不一致时，先备份本地数据，再卸载旧 APK 后安装。

## 发布

- 推送 `main`：自动构建并发布测试签名的车机 Pre-release。
- 推送 `vX.Y.Z` 标签：自动构建正式 Release，例如版本 `1.8.5` 对应标签 `v1.8.5`。
- 发布产物只包含一个通用 universal APK。

## 已知边界

本版本服务于可安装第三方 APK 的 Android 车机。它不绕过原车机桌面对第三方窗口的限制；若系统将所有第三方应用强制放入小窗，需要由车机桌面或系统设置解除该限制。方向键/旋钮的全焦点导航需要基于实车按键事件继续适配；媒体键控制由 Android 音频会话处理。

右侧系统窗口显示收音机、时间或导航，由原车 Launcher 决定；本应用不修改其内容、不请求额外屏幕空间。

## v1.8.28–1.8.29 验证与实车复核

- `npm run test:car-ui` 检查尺寸、列数、主题对比度、组件交互与系统栏边界；打包前自动运行。
- `npm run test:privacy` 检查日志脱敏与敏感文件边界。
- 实车检查深浅主题下的长中文/英文歌名、歌曲行与更多按钮、歌单卡片、空播放入口和三个控制按钮；确认右侧原车窗口未改变，实体媒体键仍可控制播放。
- 升级前建议导出本地备份；同包名同签名通常可覆盖安装，无需清除数据。
- 组件树与本地布局预览不等于 Android 原生渲染或实车验收。仓库旧版基线已有的 5 处 TypeScript 报错未由本次修改引入，完整类型检查尚未全绿。
